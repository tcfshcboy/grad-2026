# 2026 TCFSH 靠北版畢業特別企劃

這是一個專為台中一中（TCFSH）2026級畢業生打造的互動式紀念網頁。我們設計了四個不同的互動專區，讓畢業生們能一起回顧這三年來的一中點滴，補完青春的留白。

## 網站功能與服務

### 1. 🎓 一中生大會考 Bingo
這三年你到底多「一中」？專屬的 Bingo 挑戰，讓大家看看你完成了哪些一中生必做事項！
* 兩種不同版本的 Bingo 題目。
* 支援網頁直接點選連線，並自動計算連線數量。
* 提供「一般版」與「限動版 9:16」高畫質圖檔下載，方便分享至 IG 限時動態。

### 2. 📸 青澀對比 (高一 vs 高三)
歲月是把殺豬刀還是整容刀？這區讓大家上傳高一與高三的照片進行對比。
* 支援雙圖片上傳與自動壓縮。
* 可留下給自己（那時候或現在）的一句話。
* 提交資料將透過 Google Apps Script (GAS) 傳送至 Google Sheets 作為後續企劃材料。

### 3. 📍 回眸校園
一中校園的各個角落，充滿了你的哪些專屬回憶？圖文分享你對校園人事景物的戀戀不忘。
* 內建精美的校園角落示範圖（支援點擊放大預覽）。
* 可上傳自己拍攝的校園角落/景物照，並附上回憶文字與拍攝地點。
* 提交之圖文皆連動至雲端表單進行統整。

### 4. 💌 告白與感謝
有些真心話太害羞不敢當面說？愛與感謝要及時說出口！
* 匿名選項：可選擇「偷偷丟紙條」，讓系統幫你保密。
* 具名選項：選擇「勇敢留下名」，讓對方知道你的心意。
* 支援指定對象（班級/姓名/綽號/老師科目）與留言內容，透過 GAS 自動彙整。

## 技術與部署架構

本專案採用以下技術進行開發：
* **前端框架**：React 19 + TypeScript + Vite
* **樣式工具**：Tailwind CSS v4
* **動畫套件**：Motion (formerly Framer Motion)
* **圖示資源**：Lucide React
* **資料儲存欄**：透過 Google Apps Script (GAS) 串接 Google Sheets 及 Google Drive，進行文字與圖片的歸檔整理。

### 本地開發環境設置

1. 安裝依賴套件：
   ```bash
   npm install
   ```
2. 創建 `.env` 檔案（可參考 `.env.example`）：
   ```env
   VITE_GAS_WEB_APP_URL="你的_GAS_部署網址"
   ```
3. 啟動開發伺服器：
   ```bash
   npm run dev
   ```

## 部署與發布 (GitHub Actions)

本專案支援透過 GitHub Actions 自動部署至 GitHub Pages。
每當提交程式碼至 `main` 分支時，GitHub Actions 會自動執行編譯並將成品發布至 `gh-pages` 分支。

**注意**：若是部署於非根目錄（如 `https://<username>.github.io/<repo>/`），請確保 `vite.config.ts` 中的 `base` 屬性設定為正確的存取路徑（例如：`'./'`）。
